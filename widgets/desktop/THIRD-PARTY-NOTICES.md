# 桌面 Widget 的第三方依赖

当前固定 `@seelen-ui/lib` 2.8.4，npm 元数据与 LICENSE 为 AGPL-3.0-only。源码来自 https://github.com/eythaann/Seelen-UI ，本地完整许可副本为 `LICENSE-Seelen-SDK.txt`。应用固定 Seelen UI 2.8.9；应用版本与 SDK 版本分别记录，不声称完全匹配。

Widget 还使用现有锁定依赖中的 `@tauri-apps/api`，许可和上游版权文件保留在依赖目录。本项目本轮是本地体验交付；公开分发前需完成所有组件的来源、许可和对应源码交付核对。
