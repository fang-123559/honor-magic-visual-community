# Magic 视界社区版：安装与卸载

在测试账户双击单文件 EXE，首页选择“一键安装”即可使用默认数据目录。需要 Windows 11、64 位系统。分目录的开发包仍可运行“安装与卸载.cmd”。本目录应随附同一批次的 MSIX 与 setup-bundle.json；只复制向导脚本不能安装应用。

## 首次安装

1. 使用默认配置可直接点“一键安装”。如需自选数据目录或开机启动，点“自定义安装或更新…”。
2. 选择数据目录。默认是 %LOCALAPPDATA%\MagicCommunity\UserData；支持中文、空格、括号。选择专用空目录，不能使用盘根、Windows/Program Files、应用包私有目录或源码目录。
3. 开机启动默认关闭，可按自己的需要勾选。
4. 检查操作摘要后确认。Windows 负责 MSIX 的签名与信任检查；向导不自动导入证书。测试包若尚未受信任，应由维护者先完成该包的明确本机授权，不能关闭系统验证。
5. 完成后可点“创建桌面快捷方式”，从当前账户桌面启动社区版，也可以点“立即打开”。更新后该快捷方式继续指向同一应用。通知和管理员窗口助手在需要时继续使用 Windows 授权。

程序目录由 Windows 管理；所选目录只保存布局、卡片、反馈与恢复资料。不会把实际 Windows 桌面文件复制到程序安装目录。

直接安装 MSIX 后尚未配置数据时，运行本目录向导的“配置已安装版本的数据目录”。没有配置时不接管桌面。

## 更新

另一个账户的全流程验收可再次打开同一 EXE，点“一键更新”，使用内置的较高修订号。沿用原数据目录，不再询问路径；布局和卡片保留。更新前请求社区版正常退出，无法退出时停止更新，不强制关闭。

旧开发验收版绑定源码仓库。首次改用独立安装版时保留原仓库和数据，不自动迁移或删除；先正常退出旧桌面，再选择新的专用数据目录。若发现能完整核对归属的旧开发版计划任务，向导会在确认页列明，先备份再移除。无法核对的同名任务会阻止迁移，避免误动其它任务。

## 卸载与重装

运行向导，选择“卸载社区版”。默认保留布局、卡片、反馈和恢复记录，重装时可选回原目录。向导会将自己创建且仍匹配的桌面快捷方式移入回收站，保留同名或已修改的用户文件。

取消保留时，只把已核验归属的数据目录移入回收站，不永久删除，不触碰 Windows 桌面文件。若大文件夹仍收纳着实际文件，先在社区版将它们移出；向导会阻止丢失恢复记录。

Windows“设置 → 应用 → 已安装的应用”也可以卸载 MSIX，但不会显示本向导的数据选择页；独立数据目录保留。可以重新安装后通过向导整理。

MSIX 开机项随该包卸载。没有匹配归属的历史任务、其它应用、第三方扩展注册及证书不由本向导清理。

## 只看流程

单文件 EXE 可追加 --preview；分目录版本也可双击“预览安装流程.cmd”。顶部始终标明“流程预览”，不会安装、卸载、注册开机项或更改数据。

命令行可追加 -Preview -Scenario Update、Uninstall 或 Failure，检查对应页面。预览不能代替真实安装、退出恢复、升级、卸载和重装验收。

项目自身的开源许可暂未配置；依赖的许可证和来源记录随各组件保留。
