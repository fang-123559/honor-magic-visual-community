# 系统卡片源码提交模板

配套规范：`docs/desktop-cards/系统卡片开发与提交规范-v2.md`。

将本目录的 submission.json 复制到自己的源码交付目录，填写真实值，不要把模板注册到 card-catalog.json。建议附带：

- `handoff.md`：目标、接口、已知限制、冲突及回退。
- `settings-contract.md`：默认值、校验、多实例及旧设置读取。
- 本卡片的源码、检查和资源 NOTICE；已有文件的修改用 Git diff 提交。
- 原生浅深色 / DPI 截图与检查回执作为附件，提供 SHA-256；不要提交机器运行目录。

模板中所有 not_run 必须保持真实，不能为满足格式改为 pass。共享数据源、无数据源、无额外资源、无系统动作等情况写明理由即可，不要求为了凑目录增加代码。
