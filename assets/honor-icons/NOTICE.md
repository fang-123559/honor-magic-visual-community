# 荣耀图标资产归属与使用范围

本目录按用户于 2026-10-26 的要求，将指定的“官方图标-提取”库内静态图标复制为社区版受清单管理的普通资产。版权归 HONOR（荣耀）；“社区版资产”表示项目管理、打包和自动选用，不表示将版权改为社区版所有。

原始提取来源：HONOR MagicAnimation / MagicTaskbarApp Resources。来源副本由项目负责人提供；不公开其本机存储位置。
导入文件保持原始字节，逐项 SHA256 见 manifest.json。动画帧、动画大图及非图标的分析/预览文件未导入；程序不会读取原副本或荣耀安装目录。

项目负责人已确认取得对外再分发许可；图标仍归 HONOR 所有，按该单独授权再分发，不纳入本项目 AGPL 许可。既有其他来源图标及翻译的许可证不因导入而删除。

生成到 C++ 的单色 SVG 仅将中性 fill/stroke 适配为 currentColor 并统一 viewport=24；保留原几何、viewBox、透明度。彩色与渐变原件保留自身颜色。PNG 保持原件，不重复叠底板。

应用按准确的可执行文件名/固定快捷方式名匹配；自定义图标优先，未收录应用及动态第三方托盘继续采用真实图标。两套库有缺失或不同文件名，catalog.json 明确列出配对及缺失时采用的同库原件，不伪造“通透/白底”素材。

所有选用路径相对于运行包内 honor-icons；SVG 静态嵌入原生宿主，PNG 按需缩放解码，缓存限制 48 个纹理/4 MiB/单边256像素，套装切换、图形设备恢复、退出时释放。没有目录监控、定时扫描、网络下载或批量解码。
