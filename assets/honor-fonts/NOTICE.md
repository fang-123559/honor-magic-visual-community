# HONOR Sans CN runtime assets

Light, Regular and Medium are byte-identical copies of the fonts installed in
Windows Fonts on the user's computer, included at the user's request on 2026-11-07.
See `manifest.json` for the original filenames, sizes and SHA-256 values.

Copyright remains with Honor Device Co., Ltd. These files are not covered by the
community project's source-code license. The embedded font metadata points to
http://www.foundertype.com/index.php/About/bookAuth/key/my_grfs.html for licensing.
The OS/2 embedding flag is 8 (editable embedding); this flag alone is not a license
to redistribute fonts in a public application. The project owner has confirmed a
separate permission to redistribute the HONOR assets. These fonts remain excluded
from the project's AGPL-3.0-only software license and may only be redistributed
within the scope of that separate permission.

Runtime loading is application-private. The application does not install fonts in
Windows, modify the font registry, or alter these font files. HONOR Sans Design is
not bundled because the UI uses HONOR Sans CN and the additional file is 27 MB.
